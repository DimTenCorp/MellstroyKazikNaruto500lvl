# MellstroyKazikNaruto500lvl — слот-машина 3×5 для Яндекс.Игр

Казино-игра (без реальных денег) на Godot 4.7. Главное поле — сетка **3 строки × 5 барабанов**,
символы берутся из `img/slot_machine/`.

## Запуск

Открой проект в Godot 4.7 (GL Compatibility) и нажми F5 — главная сцена `scenes/game.tscn`.
Для веба используй экспорт-пресет Web, который создаёт плагин Yandex Games SDK
(автолоад `YandexGames` уже прописан в `project.godot`).

### Как менять размер кнопок

У Control-узлов (кнопки тоже Control) кликабельная область — это прямоугольник
`Position/Size` в секции Layout инспектора. Свойство `Scale` меняет ТОЛЬКО отрисовку,
хитбокс остаётся старого размера. Поэтому: сбрось `Scale` в (1, 1) и задавай нужный
размер через `Size` (и `Position` при необходимости) — спрайт и хитбокс совпадут.
Если до этого кнопка была отмасштабирована: новый `Size` = старый `Size` × `Scale`,
потом `Scale` = (1, 1). Для фигурных хитбоксов у TextureButton есть `click_mask`
(BitMap), но обычно достаточно обычного `Size`.

Весь UI лежит узлами прямо в `game.tscn`: открыв сцену, в дереве и в 2D-виде видны
рамка, барабаны `Reel0..Reel4` с ячейками `Cell0..Cell3`, панели, кнопки и попап
таблицы выплат. Динамика (ленты, подсветка линий, баннеры) добавляется кодом в
`fx_layer` / `lines_overlay`. Если нужно пересобрать макет из констант —
`python3 tools/gen_game_tscn.py` (сотрёт ручные правки сцены).

## Файлы

| Файл | Назначение |
| --- | --- |
| `scripts/slot_data.gd` | вся математика: символы, веса, таблица выплат, 9 линий, оценка спина |
| `scripts/reel.gd` | один барабан: бесконечная прокрутка ленты, остановка на заданных символах, отскок |

| `tools/gen_game_tscn.py` | генератор `game.tscn` из констант макета (перезаписывает сцену целиком!) |

## Правила игры

* **Ставка**: выбирается ставка на линию (1…50), полная ставка = ставка × 9 линий.
* **Линии**: 9 фиксированных линий (см. «ТАБЛИЦА» в игре). Линия платит, если от первого
  барабана слева подряд совпали 2–5 символов (для вишни/лимона/апельсина платится и пара).
* **WILD** (золотая монета): заменяет любой символ, кроме BONUS; линия из одних WILD платит
  по таблице WILD (до 10000 ставок линии за 5).
* **BONUS** (сундук, скаттер): 3/4/5 в любом месте поля = 2/10/50 **полных** ставок
  + 10/15/20 фриспинов. Во фриспинах ставка не списывается, возможен ретриггер.
* **Ценность символов** (ставка линии × множитель за 3/4/5):
  777 — 250/1000/5000, BAR×3 — 150/600/2500, BAR×2 — 100/400/1600, BAR — 75/300/1200,
  колокол — 50/200/800, мешок — 40/150/600, подкова — 30/100/400, звезда — 25/80/300,
  арбуз — 20/60/200, слива — 15/40/150, апельсин — 12/30/120 (пара 2),
  лимон — 10/25/100 (пара 2), вишня — 10/25/100 (пара 2), WILD — 500/2000/10000.
* **Большие выигрыши** показывают всплывающий бейдж из `img/win` (RU):
  ≥10 полных ставок — «БОЛЬШОЙ ВЫИГРЫШ», ≥20 — «СУПЕР», ≥40 — «МЕГА»,
  ≥80 — «ЭПИЧЕСКИЙ», ≥150 — «ДЖЕКПОТ»; во фриспинах — «В БОНУСНОЙ ИГРЕ»,
  при скаттере — «БОНУС», при ретриггере — «ФРИСПИН».
* **Кнопки интерфейса** — спрайты из `img/buttons_spr/buttons_sprites.png` (RU),
  раскладка заказчика (коммит 91dc2e5), перенесённая в координаты макета 1280×720:
  ПУСК (спин / стоп автоигры), АВТОИГРА (меню числа спинов), МАКС. СТАВКА,
  СТАВКА (меню выбора ставки), УСКОРЕНИЕ (цикл ×1 → ×2 → ×5, каждое переключение
  показывает текст «СКОРОСТЬ ×N»), ТАБЛИЦА ВЫПЛАТ, ЗВУК (меню громкости).
  Кнопки НОМИНАЛ МОНЕТЫ и ЗАБРАТЬ удалены заказчиком: номинал выбирается в меню
  ставки, автоигра останавливается кнопкой АВТОИГРА или ПУСК.

## Меню (всё узлами в `game.tscn`, скрыты до открытия)

* **`bet_menu`** — ставка на линию 1/2/5/10/25/50 (сетка 3×2) + «Полная ставка: N»;
  открывается кнопками СТАВКА и НОМИНАЛ МОНЕТЫ (во время спина заблокировано).
* **`auto_menu`** — число автоспинов 10/25/50/100/∞ (без лимита) + «ОТМЕНА»;
  открывается кнопкой АВТОИГРА, повторное нажатие останавливает серию.
  Счётчик серии виден сверху («АВТО: N»), АВТОИГРА и ПУСК останавливают её,
  при нехватке монет серия прерывается баннером.
* **`sound_menu`** — ползунки «Звуки» и «Музыка» 0…100 (пока тишина: аудиофайлы
  добавим позже). Шины `SFX` и `Music` создаются в `_ready`, громкость
  применяется через `linear_to_db`, 0 = mute; значения сохраняются в сейв.
* Закрытие любого меню: кнопка «ЗАКРЫТЬ», клик по затемнению или Esc.
* Заголовок «ЗОЛОТЫЕ БАРАБАНЫ» и счётчик «Всего:» удалены по просьбе заказчика.
* **Баланс** показан иконкой мешка денег `img/slot_machine/moneysack.png` + число:
  узел `balance_icon` рядом с `balance_label` в верхней панели.
* **Фон** — `img/background/back1.jpg` (под таблицей выплат — back2.jpg).
* **Баланс** хранится в `user://slot_save.cfg`; если монеты кончились — кнопка «БОНУС +1000».

## Мат. модель

Веса символов на ячейку (чем ценнее, тем реже): вишня 34, лимон 32, апельсин 30, слива 26,
арбуз 24, звезда 20, подкова 17, мешок 14, колокол 12, BAR 10, BAR×2 8, BAR×3 6, 777 5,
WILD 11, BONUS 6. При этих весах и таблице симулятор даёт **RTP ≈ 94.7 %**, хит-рейт ≈ 46 %,
триггер скаттера ≈ 0.5 % спинов. Меняя баланс — правь `slot_data.gd` и `tools/rtp_sim.py`
синхронно и прогоняй симуляцию.
